# python-practice

This repository contains Python practice exercises and data analysis completed during my training.
 
## Student Data Analysis
 
This project uses Python and Pandas to carry out exploratory data analysis (EDA) on a student dataset.
 
The analysis includes:
- Previewing the dataset
- Checking the size of the dataset
- Checking data types
- Checking for missing values
- Calculating the average, highest, lowest and median student mark
- Identifying students with marks over 70
 
## Dataset
The dataset can be found in the `dataset` folder.
 
## Source Code
The Python EDA can be found in `student-analysis-python-code.py`.
